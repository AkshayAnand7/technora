SmartFactory

A decentralized auction-based dispatch and digital twin system for smart factories. Predicts future congestion bottlenecks and downstream disruptions before assigning vehicles.

▶ Launch Live Simulation

Traditional Dispatch

"Which AGV is closest right now?"

Optimizes single-task proximity greedily. Funnels multiple vehicles into the same narrow corridors, triggering severe traffic delays downstream.

SmartFactory MarketFloor

"Which AGV causes the least future impact?"

Multi-attribute market auction evaluating travel, real-time corridor congestion, future downstream impact heuristic, battery levels, and workload fairness.

HOW IT'S BUILT

System architecture

Frontend HTML5 Canvas & Vanilla JS — live factory dashboard, real-time controls & telemetry
Backend Python / FastAPI — WebSocket state streaming, REST APIs, asyncio tick loop
AI Layer Market-Based Auction Engine — multi-attribute bidding & future-impact congestion heuristic
Database SQLite Database — task history, auction bids, completion times & throughput analytics
Simulation Discrete-Event Tick Loop — A* congestion routing, battery cycles & failure recovery
